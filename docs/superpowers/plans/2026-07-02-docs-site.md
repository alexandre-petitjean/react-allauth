# Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement phase 5 of the road-to-1.0 spec: a VitePress documentation site under `docs/site/`, deployed to GitHub Pages, linked from the README.

**Architecture:** VitePress with `srcDir: docs/site`, config in `docs/site/.vitepress/config.ts`, base `/react-allauth/` for project pages. Content: getting started, backend configuration, error handling, one page per hook. A `docs` GitHub Actions workflow builds and deploys on pushes to master.

**Tech Stack:** vitepress (devDependency), GitHub Pages via actions/deploy-pages.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-02-road-to-1.0-design.md`.
- Page content is authored at execution time directly from the hook sources (all hook signatures are in `src/hooks/*.ts`); each hook page must show: what it does, the full result interface, one runnable example, error-handling notes. No fabricated APIs — copy signatures from the source.
- Commit messages: single line, imperative. `pre-commit run -a` before each commit.
- No Windows sections in docs; linux/macos only.

**Files:**
